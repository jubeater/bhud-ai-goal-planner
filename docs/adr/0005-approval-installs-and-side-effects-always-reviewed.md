# Installs, Marker Pack downloads and Side Effects always need Review

The Player wants the AI to configure things automatically, but installs and downloads bring in third-party code and content, and Side Effects change things the Player didn't ask about. Setting changes may be Auto-applied if the Player turns that on (off by default), because Undo covers them. Installs, Marker Pack downloads and Side Effects always go through Review, even with Auto-apply on.

## Considered Options

- **Always Review everything.** Safest, but slower than the Player wants.
- **Fully automatic, including installs.** Rejected: one bad Plan could install unwanted code with full trust.
